## About

I build terminal tools in Python, and I work on running large language models locally on ordinary hardware.

## Featured projects

### [keyflow](https://github.com/YnsLaf/keyflow)

A colorful typing trainer for the terminal: time tests, an endless survival mode, 40 stories in English and German, and an on-screen keyboard that highlights the next key.

Published on PyPI as [`keyflow-typing`](https://pypi.org/project/keyflow-typing/) — the name `keyflow` was already taken. The command is `keyflow`. It needs Python 3.8 or newer.

```bash
pip install keyflow-typing
```

### [flowllm](https://github.com/YnsLaf/flowllm)

Work in progress. Runs large language models on ordinary hardware by streaming layers and loading parameters sparsely.
